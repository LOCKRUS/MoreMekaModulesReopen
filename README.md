# MoreMekaModulesReopen

Additional Mekanism modules for Minecraft 1.21.1.

This is the reopened fork of the original More MekaSuit Modules project. The technical mod ID and resource namespace remain `moremekasuitmodules` to preserve compatibility with existing worlds, configurations and installed modules.

This repository was based on https://github.com/sddsd2332/MekanismMoreMekaSuitModules
